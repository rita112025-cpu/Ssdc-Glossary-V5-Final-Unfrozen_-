軟體工程術語表
去敏公版

給剛開始接觸 Git / CI / 部署 / 程式碼品質工具的人查用的通用術語表。

大綱

Git 基礎

Repo儲存庫

Git 中存放程式碼與版控紀錄的專案單位。

clone複製儲存庫

將遠端 Repo 完整下載到本地的操作。

blobless clone無 blob 複製

Git clone 時不下載檔案內容（blob），只拿 commit 與樹結構的省流量方式。

ls-remote遠端列表指令

不需 clone 就能列出遠端分支與標籤的 Git 指令。

refs參照

Git 中指向 commit 的分支、標籤等指標的總稱。

origin遠端來源

Git 中預設遠端倉庫的名稱。

main / master / develop主分支名稱

Git 預設或開發用的主要分支名稱慣例。

SHA提交雜湊值

Git 中每次 commit 的唯一識別碼，通常以 40 字元十六進位表示。

hook鉤子

Git 在特定時機自動執行的腳本。

huskyGit 鉤子管理工具

用來在本地掛載 commit-msg 等鉤子、強制檢查提交訊息格式的工具。

--no-verify跳過鉤子

Git 參數，可跳過 pre-commit 與 commit-msg 鉤子，使用時應在提交說明中註明原因。

.gitignore忽略清單

告訴 Git 哪些檔案不該提交，例如憑證檔。

CI 與自動化

.github.github 目錄

存放 GitHub Actions workflow 等設定檔的隱藏目錄。

workflow工作流程

GitHub Actions 中定義自動化步驟的 YAML 檔。

workflow_dispatch手動觸發

允許在 GitHub 網頁上手動按鈕觸發 workflow 的觸發條件。

push / pull_request / schedule觸發條件

GitHub Actions 常見的觸發事件類型。

CI持續整合

程式碼提交後自動執行建置與測試的流程。

pytestPython 測試框架

Python 測試框架與其設定檔 pytest.ini。

lint / eslint程式碼風格檢查

檢查程式碼語法與風格是否符合規範的工具。

安全掃描Security Scan

掃描相依套件漏洞或機敏資訊的檢查。

test script測試指令

package.json 中定義的 npm test 等測試執行指令。

check檢查狀態

GitHub 上 PR 所需的 CI 檢查結果是否全綠。

audit:production生產環境稽核

npm audit 只檢查生產依賴的漏洞掃描指令。

--runxfail預期失敗參數

pytest 參數，使 xfail 標記不再生效，測試按一般測試執行與判定。

compileallPython 語法編譯檢查

Python 內建工具，將原始碼全部編譯以檢查語法錯誤。

symlink 邊界檢查符號連結安全檢查

檢查 symlink 是否指向倉庫外部的安全機制，避免任意檔案寫入。

型別檢查Type Checking

檢查變數型別是否正確的靜態分析。

供應鏈稽核Supply-chain Gate

檢查第三方套件是否安全的 CI 關卡。

lock 檔相依鎖定檔

記錄確切套件版本的檔案，例如 package-lock.json，用於重現一致的建置環境。

Dependabot / secret scanningGitHub 安全功能

自動更新依賴、掃描機密與程式碼漏洞的 GitHub 內建功能。

分支保護規則保護與審批規則

限制分支合併條件、以及部署環境需人工審核的設定。

ghGitHub CLI

GitHub 官方命令列工具。

部署與雲端

Workload Identity Federation工作負載身份聯邦

用短期令牌取代長期金鑰，讓 CI 安全存取雲端服務的機制。

SA JSON 金鑰服務帳號金鑰

雲端服務帳號的長期憑證 JSON 檔，外洩風險較高，建議優先改用短期令牌機制。

VM虛擬機

部署目標的一種型態，服務跑在持續運作的虛擬主機上。

:latest最新標籤

Docker 映像常見的預設標籤名稱；是否真的指向最新版，取決於映像發布流程。

checkout檢出

CI 流程中將程式碼取出到執行環境的步驟。

金絲雀部署Canary

先以極小流量或零流量部署新版本、驗證通過後才逐步切換流量的部署策略。

Artifact Registry產物倉庫

雲端服務中存放建置產物（如 Docker 映像）的服務。

gcloudGCP 命令列工具

操作 Google Cloud 服務的命令列工具。

套件漂移Package Drift

比對新舊建置產物實際安裝的套件版本是否一致的檢查。

煙霧測試Smoke Test

部署後快速驗證服務是否存活的基本測試。

401 / 404 / 410HTTP 狀態碼

401 未授權、404 找不到、410 已永久移除。

程式碼品質與前端

AST抽象語法樹

解析程式碼結構、用於靜態分析的樹狀資料結構。

prop屬性

前端框架（如 React）元件傳入的參數。

Optimistic Update樂觀更新

先假設操作會成功、立即更新畫面，再等待伺服器實際回應的互動模式。

aria-label / WCAG AA無障礙標準

網頁無障礙屬性標籤、跳過導覽連結，以及 AA 級無障礙合規標準。

bearer token持有者令牌

API 認證用的令牌，通常放在 HTTP Header 中傳遞。

常見縮寫

CRM客戶關係管理系統

Customer Relationship Management，管理客戶互動與銷售流程的系統類型。

ERP企業資源規劃系統

Enterprise Resource Planning，整合財務、人資、供應鏈等企業流程的系統類型。
